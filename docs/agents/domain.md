# Domain Docs

## Layout

Single-context — one `CONTEXT.md` at the repo root, one `docs/adr/` directory.

## Consumer rules

- **CONTEXT.md** (repo root): Project overview, tech stack, key conventions. Read this first when onboarding to the project.
- **docs/adr/**: Architecture Decision Records. Read when making or reviewing architectural changes.

## Reading order

1. `CONTEXT.md` — always read first
2. `docs/adr/*.md` — read when the topic is relevant to your task
