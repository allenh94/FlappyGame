# Triage Labels

## Canonical roles

| Label | Meaning |
|---|---|
| `needs-triage` | New issue awaiting triage classification |
| `needs-info` | Blocked — needs more information from reporter |
| `ready-for-agent` | Triaged and ready for an AI agent to pick up |
| `ready-for-human` | Triaged and requires human action |
| `wontfix` | Reviewed and decided not to act on |

## Usage

- `triage` skill applies these labels during issue processing
- Labels are used as directory-level status indicators in `.scratch/`
